# **App Name**: FinTrack

## Core Features:

- Transaction Input: Simple form to input income and expenses with amount, date, and category.
- Categorization: Automatic and manual categorization of transactions.
- Budget Setting: Set monthly budget limits for various categories.
- Budget Tracking: Monitor spending against budget goals with visual progress indicators.
- Spending Trends: Interactive charts displaying spending trends over time.
- Financial Insights Dashboard: Clean dashboard presenting key financial metrics at a glance.
- AI-Powered Budgeting Assistant: Use AI to provide smart recommendations on setting budget limits and identifying areas for savings; the AI tool can use past spending habits to decide what kind of advice to give.

## Style Guidelines:

- Primary color: Cool-toned light blue (#A7D1AB) for trustworthiness and serenity.
- Background color: Very light blue (#F0F4F7).
- Accent color: Slightly darker, slightly more saturated green (#92B896) for contrast and engagement.
- Font: 'Inter', a sans-serif font, for both headlines and body text, giving a modern, clean, and readable appearance.
- Use minimalistic, outlined icons for categories and actions.
- Clean, spacious layout with a focus on readability and clarity.
- Subtle transitions and animations to provide feedback and enhance user experience.
